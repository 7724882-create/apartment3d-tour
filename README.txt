3D-тур по квартире — статический сайт, без сервера и без внешних CDN.
Точка входа: index.html. Страница «Фото на плане»: plan.html.
Загрузите всю папку на любой статический хостинг (Netlify, GitHub Pages, S3, обычный хостинг).
Открывать файл двойным щелчком нельзя (браузер блокирует модули с file://) — нужен веб-сервер,
например: python3 -m http.server  и затем http://localhost:8000/

Встраивание на сайт:
<iframe src="https://ВАШ-САЙТ/apartment3d/index.html" width="100%" height="640"
        style="border:0;border-radius:12px" allow="fullscreen" allowfullscreen loading="lazy"></iframe>

Параметры ссылки: ?view=x,z,направление — начать с точки; ?mode=overview — начать с обзора сверху; ?hq=0 — без мягких теней (для слабых ПК).

Версия 2 (по фотографиям владельца):
- Все фото в photos/ — присланные оригиналы. Текстуры в tex/ (обои, линолеум, ковры, ткани, фасады кухни,
  дерево мебели, плитка, ПВХ-панели, шторы, скатерть) вырезаны из этих фото и сделаны бесшовными.
- За окнами — панорама из реальных видов (tex/panorama.jpg, собрана из view.jpg, balcony.jpg, loggia.jpg, kitchen-*.jpg).
- Кнопка «📸 Фото-слой»: если встать на точку съёмки (галерея → «Встать на точку съёмки в 3D»),
  поверх модели плавно появляется настоящая фотография из той же точки и с тем же углом обзора.
  ?photos=0 — выключить фото-слой при запуске.
